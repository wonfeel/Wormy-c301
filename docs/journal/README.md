# Журнал калибровок

Рабочие отчёты по версиям модели (V2-V5): что проверялось, что получилось,
что откатили. Лежат здесь, а не в `demo/worm/`, чтобы корень демки оставался
кодом, а не свалкой логов - но и не удалены, потому что половина из них
фиксирует **отрицательные** результаты, а это самая полезная часть истории:
видно, какие ходы уже пробовали и почему они не сработали.

Читать не обязательно для работы с кодом - за актуальным состоянием модели
идти в [demo/worm/WORM.md](../../demo/worm/WORM.md). Эти файлы - срез на
момент своей фазы, задним числом они не переписывались.

Порядок примерно хронологический:

| Файл | О чём |
|---|---|
| `WORM_V2_DESIGN.md` / `WORM_V2_RESULTS.md` | Переход на v2-архитектуру, первые прогоны |
| `WORM_V2_MECHANOSENSATION_JOINT_RESULTS.md` | Совместный поиск mechanoGain/localMechanoGain - **чистый отрицательный результат** |
| `WORM_V3_DESIGN.md` / `WORM_V3_RESULTS.md` | v3 |
